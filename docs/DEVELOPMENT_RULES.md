# Charte technique pour IA de développement

Version : 1.0
Projet : TableFlash Leads Engine (TFLE)
Audience : Codex / Claude Code / Cursor / Développeurs


# 1. OBJECTIF DU DOCUMENT

Ce document définit les règles obligatoires de développement du projet TFLE.

Toute intervention technique doit respecter ces principes afin de garantir :

- stabilité du projet ;
- maintenabilité du code ;
- évolutivité architecture ;
- sécurité ;
- cohérence avec la vision produit.


# 2. RÈGLE PRINCIPALE

Avant toute modification :

COMPRENDRE → PLANIFIER → MODIFIER → TESTER → DOCUMENTATER


Aucune modification importante ne doit être effectuée sans analyse préalable.


# 3. COMPORTEMENT ATTENDU DE L'IA DE DÉVELOPPEMENT

L'IA agit comme :

- Architecte logiciel ;
- Développeur senior ;
- Responsable qualité technique.


Elle doit :

- analyser le contexte existant ;
- comprendre l'architecture actuelle ;
- identifier les impacts ;
- proposer une approche ;
- expliquer les changements réalisés.


Elle ne doit pas agir comme un simple générateur de code.


# 4. RÈGLES AVANT MODIFICATION DU CODE


Avant toute modification majeure :

L'IA doit fournir :

1. Objectif du changement

2. Fichiers concernés

3. Impact potentiel

4. Plan d'exécution

5. Méthode de validation

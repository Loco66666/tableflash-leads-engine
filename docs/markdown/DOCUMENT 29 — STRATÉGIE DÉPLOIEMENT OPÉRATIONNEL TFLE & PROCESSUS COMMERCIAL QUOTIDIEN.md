# **29.13 --- Gestion objections**

TFLE possède une bibliothèque.

## **\"Je n\'ai pas besoin de ça\"**

Réponse IA :

L\'objectif n\'est pas de remplacer votre fonctionnement actuel mais
d\'ajouter une possibilité supplémentaire pour vos clients.

## **\"C\'est compliqué\"**

Réponse :

La plateforme est pensée pour rester simple : vous gérez votre menu
comme un catalogue classique.

## **\"Je préfère parler avec mes clients\"**

Réponse :

Le contact humain reste essentiel. TableFlash permet simplement de
réduire l\'attente quand le client le souhaite.
